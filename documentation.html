How LightShare Works (User Guide)

1. Connect to Same Wi-Fi or Hotspot

Ensure both devices are on the exact same Wi-Fi router or turn on Mobile Hotspot on Sender.

2. Scan In-App Camera QR Code

Open LightShare on Receiver and point the camera at Sender's screen to connect instantly.

3. Multi-Select Any Files (Up to 30GB+)

Pick Photos, 4K Videos, Audio tracks, Apps/APKs, Documents, or huge ZIP archives with strict category filtering.

4. Direct Stream & Save

Files stream directly to device storage with real-time speed gauges (50–100+ MB/s on 5GHz Wi-Fi).

Hotspot Mode Directions

Android Hotspot

Enable Personal Hotspot. Connect devices. Target IP automatically resolves to 192.168.43.1.

iPhone Hotspot

Enable Personal Hotspot. Connect devices. Target IP defaults to 172.20.10.1.

Windows PC Hotspot

Enable Windows Mobile Hotspot. Connect phones. Target IP defaults to 192.168.137.1.
